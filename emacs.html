1. Split Custom Files

This bit of code splits all emacs writing of custom variables to a different file. This just keeps my init.el file looking like I expect. 

  ; When you do automatic config changing, put the changes in custom.el
  ; instead of this init file
  ; Change
(setq custom-file
      (expand-file-name "custom.el" user-emacs-directory))

(when (file-exists-p custom-file)
  (load custom-file))

10.2. Vscode Terminal Buffer

10.2.1. Function

Launch vscode like terminal in vertically split buffer 

  (defun launch-xterm ()
    (interactive)
    (let ((buf (get-buffer "vscode-vterm-window")))
      (if (and buf (get-buffer-window buf))
          ;; If it's visible, hide it
          (delete-windows-on buf)
        ;; If it's hidden or doesn't exist, display it
        (let ((new-win (split-window-below)))
          (select-window new-win)
          (if buf
              (switch-to-buffer buf)
            (vterm "vscode-vterm-window"))))))

10.2.2. Keybind

Open Vscode terminal in vertical buffer with C-`. 

  (global-set-key (kbd "C-`") 'launch-xterm)
