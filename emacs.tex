\section{Split Custom Files}
\label{sec:orgef8d29a}
This bit of code splits all emacs writing of custom variables to a different file. This just keeps my \texttt{init.el} file looking like I expect.

\begin{Code}
\begin{Verbatim}
\color{EFD}                                          \EFcd{; }\EFc{When you do automatic config changing, put the changes in custom.el}
                                          \EFcd{; }\EFc{instead of this init file}
                                          \EFcd{; }\EFc{Change}
  \EFrda{(}\EFk{setq} custom-file
        \EFrdb{(}expand-file-name \EFs{"custom.el"} user-emacs-directory\EFrdb{)}\EFrda{)}
  \EFrda{(}load custom-file\EFrda{)}
\end{Verbatim}
\end{Code}
